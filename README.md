# MetaKnight HQ

Central hub for the MetaKnight project: documentation, decisions, plans, and shared assets.

## Layout

| Path | Purpose |
| --- | --- |
| `docs/` | Plan, brand tokens, business context, decision records |
| `brand/` | Logo and icon |
| `docs/decisions/` | Architecture and product decision records |
| `.github/` | Issue and pull request templates |

## Getting started

```bash
git clone git@github.com:ma-stha/MetaniteHQ.git
cd MetaniteHQ
```
